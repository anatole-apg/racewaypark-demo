# Raceway Park Archive — public demo

A static, searchable demo of digitised 35mm drag-racing negatives from Raceway
Park, Englishtown NJ.

Every photograph here is a **watermarked, resolution-capped, metadata-stripped
preview**. Archival masters are not in this repository and are not reachable
from it. Frames whose crop is still awaiting human review are not published and
are absent from this bundle entirely — not their pictures, not their tags, not
their identifiers.

Details shown against a frame were read automatically by on-device text and
image recognition. They are labelled **machine suggestion** until an operator
confirms or corrects them. Nothing here is a verified historical record.

Built from the project's own public-view allowlist; this repository holds only
generated output.
